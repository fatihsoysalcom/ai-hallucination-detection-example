# AI Hallucination Detection Example

This example demonstrates how AI models can 'hallucinate' by providing incorrect or fabricated information. It then shows a simple defense mechanism: verifying the AI's output against a trusted, factual knowledge base. This helps identify and flag potentially unreliable AI responses, illustrating a core concept of mitigating AI hallucinations.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
